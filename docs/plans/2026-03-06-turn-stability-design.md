# Turn Stability Design

**Date:** 2026-03-06

## Goal

在保留明显弯身转向表现的前提下，大幅降低金鱼在贴边避障大弧线转向、跟随手指急转、突然掉头时出现的身体扭曲、局部反折和视觉折叠。

## Problem Summary

当前转向链路由 4 层共同作用：

1. `SteeringAgent` 根据 steering force 改变头部速度和角速度。
2. `GoldfishEntity.applyTurnBodyFlex()` 基于 `angularVelocity` 对中段脊椎粒子施加统一方向的弯体力。
3. `FishMotionDriver` 再对整条脊椎施加摆尾波。
4. `MeshDeformer` 根据脊椎角度和横向宽度做网格变形。

问题不在单一参数，而在这些层在高角速度场景下同时争抢控制权：

- 主动弯体使用 `headAngle` 的全局横向方向，忽略了当前局部脊椎切线。
- 中段多个粒子同向受力，容易在已经弯曲的脊椎上产生二次内折。
- 边界钳位只修正位置，不修正朝向内侧的速度分量，导致头部被“卡住”而身体仍尝试继续压向墙侧。
- 网格虽然有基础角度平滑和宽度压缩，但对高曲率局部折叠的保护还不够强。

## Chosen Approach

采用“分层转向弯体 + 稳定器”的方案：

1. 保留主动弯体，但将其改为沿脊椎传播的延迟弯曲，而不是一次性把同向力压给中段。
2. 弯体方向改为使用每个粒子的局部横向方向，避免局部切线和全局头向冲突。
3. 为转向弯体增加平滑状态和最大增长速率，防止急转时瞬间打满。
4. 恢复边界钳位时对朝墙速度分量的消除，降低贴边场景的头身对冲。
5. 加强渲染层高曲率区的宽度保护，优先防止局部视觉折叠。

## Component Changes

### 1. Steering / Bounds

- `GoldfishEntity.clampAgentToBounds()` 在碰到边界时同时修正 `position` 和朝外侧反方向的 `velocity` 分量。
- 目标不是减少转弯，而是避免“头停住但速度还想继续撞墙”的假信号传给后续弯体层。

### 2. Turn Flex Controller

新增一个纯逻辑控制器，负责把 `angularVelocity` 映射成“沿身体传播的转向弯曲”：

- 输入：当前角速度、`dt`、粒子索引、粒子总数、局部横向方向。
- 输出：每个粒子的附加弯体力。
- 内部状态：
  - 平滑后的 turn intensity
  - 当前 turn sign / bend phase
  - 强度变化速率限制

行为特征：

- 头后部较快进入弯曲，腹部达到峰值，尾部延迟跟随。
- 颈部和尾根保持更硬，避免直接折断。
- 当前转向方向反转时，旧方向弯曲先释放，再建立新方向弯曲，避免瞬间 S 折。

### 3. Spine / Curvature Stability

- 主动弯体应用时使用局部 lateral，而不是 `headAngle` 的统一 lateral。
- 限制单帧弯体增量，优先通过时间传播形成大弧线，而不是单帧暴力内压。
- 保留 `SpineChain` 的最大角约束，作为最终硬护栏。

### 4. Mesh Fold Guard

- 在 `MeshDeformer` 中加强高曲率区的横向收窄。
- 仅在高曲率中后段明显触发，避免把正常的强弯体视觉整体削弱。
- 保持当前较细致的 spine-axis 采样，不回退到更粗网格。

## Validation Strategy

由于仓库没有现成测试 target，这次先补可执行的 Swift 验证脚本，作为 TDD 红灯入口：

1. 边界钳位测试
   - 头部进入边界后，朝墙速度分量必须清零。

2. 弯体传播测试
   - 高角速度连续左/右转时，中腹弯曲强度应高于颈部和尾根。
   - 弯曲沿身体应保持同向主导，不能在中段形成明显交替反折。

3. 方向反转测试
   - 左转切右转时，弯曲峰值应先释放后反向，不允许单帧直接翻折。

4. 渲染护栏测试
   - 高曲率时 `MeshDeformer` 的局部宽度压缩应比普通曲率更强。

## Non-Goals

- 不追求完全消除所有形变瑕疵。
- 不对整个游动状态机重构。
- 不把弯体完全移到纯渲染层。
